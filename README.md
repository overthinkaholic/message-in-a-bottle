# Message In A Bottle...
> **문학, 음악, 게임의 한 구절을 건져 올리는 레트로 앰버 터미널 생성기**

`Message In A Bottle...`은 문학 구절, 음악 가사, 게임 명대사 등을 무작위로 추출해 감상할 수 있는 감성적인 단일 페이지 웹 애플리케이션(SPA)입니다. 

브라우저에서 바로 열어 사용할 수 있는 초경량 구조로 설계되었습니다.

---

## 기능 특징

1. **다중 태그 필터링 (OR 필터)**
   - 대분류(전체, 문학, 음악, 게임)를 선택하면 하위 태그들이 동적으로 정렬됩니다.
   - 여러 태그를 한 번에 다중 선택하여 특정 범위 내의 구절만 집중적으로 추출할 수 있습니다.

2. **클립보드 간편 복사 및 토스트 팝업**
   - `COPY` 버튼을 누르면 화면에 나타난 한국어/영어 대사 및 출처 메타데이터가 완벽히 포맷팅되어 클립보드에 저장되며, 우측 하단에 깜빡이는 주황색 토스트 알림창이 나타납니다.

3. **연속 중복 생성 방지**
   - 동일한 조건의 구절 풀(Pool)이 2개 이상 존재할 때, 직전에 감상한 구절이 연속해서 다시 나오지 않도록 자동 보정 처리가 내장되어 있습니다.
